# 交点泊序 · 西南交通大学犀浦校区车辆泊序管理平台

面向西南交通大学（犀浦校区）保卫科与后勤处打造的轻量化、强可视化校园非机动车（自行车/电动车）泊序治理 Web App，重点解决**早八教学楼与晚间宿舍区潮汐拥堵**及**毕业季遗留僵尸车难界定、难清理**两大校园管理痛点。

## 核心功能

- **3D 态势（离线真 3D 校园白模）**
  - 基于 OpenStreetMap 真实轮廓离线渲染西南交大犀浦校区 **258 栋 3D 建筑**（含 1–9 号教学楼与综合楼中庭、图书馆、天佑斋 1–22 栋、鸿哲斋、一至五食堂、体育馆、后勤保卫处等）、378 条路网、9 处水系与 98 处绿地/球场，零外部瓦片依赖、离线秒开。
  - 贴地柔光热力圆环 + 3 条校园主干潮汐走廊 + 24 小时作息时间轴（支持正常教学日 / 雨天模式 / 周末场景推演与自然太阳光影变化）。
  - 支持楼栋快搜、点击真实建筑定位最近泊车区、消防通道禁停红线图层、以及在地图上直接点选坐标上报违停。
- **僵尸车全生命周期治理台账**
  - 「巡检登记（含现场照片上传）→ 贴码公示 → 车主扫码认领（我还在用/自愿清运）→ 逾期清运入库」全流程闭环。
  - 支持单张与 **A4 两栏批量打印离线二维码公示贴纸**，支持一键导出带 UTF-8 BOM 的 Excel CSV 公示清单。
- **保卫科执勤工单中心**
  - 统一调度潮汐疏导、违停占道与僵尸车清运工单，支持班组指派、状态流转（待派发 → 执勤处理中 → 已完成销项）及 CSV 导出。
- **泊序决策简报**
  - 纯 SVG 24 小时教学区 vs 宿舍区潮汐剪刀差曲线、高频拥堵黑点 Top 5、实时联动僵尸车治理漏斗，支持一键打印/导出 PDF 周报。
- **后台管理系统（实时联动）**
  - 支持实时调整各停车区规划泊位容量（`-20/+20` 步进）、雨棚属性、拥堵/预警阈值、贴码公示周期、网格值班班组管理，内置完整审计日志与 JSON 离线数据备份/恢复。
- **师生微信微端预览 & 手机端原生适配**
  - 内置师生微端实时预览（推荐 Top 3 空闲泊位、爆满绕行提醒、车身编号快速认领）；手机端（≤ 768px）自动切换为底部 5-Tab 原生导航栏、Bottom Sheet 详情抽屉与触控卡片视图。

## 技术栈与规范

- React 19 + TypeScript + Vite 6 + MapLibre GL
- 遵循 [GoogleChrome/modern-web-guidance](https://github.com/GoogleChrome/modern-web-guidance)（原生 `<dialog>`、Popover API、`@starting-style`、`transition-behavior: allow-discrete`、现代 CSS 嵌套与 `color-mix()`，`legacy-scan` 0 告警）
- 地理数据来源：OpenStreetMap Contributors（Overpass API 本地静态化）
